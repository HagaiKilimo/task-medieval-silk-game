# task-medieval-silk-game
Menu-driven game to create cities, generate tax, and lose cities depending on trade.
Welcome to the Medieval Silk Game, you can create new cities with the tax your empire generates. Cities cost and generate tax according to their name length. For example, Venice would cost 6 ducats. Trade brings in up to 10000 bolts of silk per year. If trade is less than 200 bolts, a city loses its independence. You start with these cities: Lucca, Treviso, Turin, Vercelli.
